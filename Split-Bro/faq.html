Frequently Asked Questions

Find quick answers about groups, expenses, splitting and settlements in Split Bro.

Split Bro is a web application that helps groups manage shared expenses, split costs and understand who needs to pay whom.

Go to the Groups page and create a new group. A unique group code is generated, which can be shared with other members so they can join the same group.

Use the Join Group option and enter the group code shared by a member of that group.

Split Bro supports equal splitting, percentage-based splitting and custom amounts, depending on how the group wants to divide an expense.

The Settlement feature calculates the net balance of each member and helps identify who should pay and who should receive money to settle the group's expenses.

The Fairness Detector compares contributions and expense shares to help the group understand how evenly the spending responsibility is distributed.

In the current version of Split Bro, application data is stored in the browser using localStorage. This allows the data to remain available even after refreshing the page in the same browser.
