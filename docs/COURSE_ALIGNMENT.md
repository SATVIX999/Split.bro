# Split Bro — Course Plan Syllabus Alignment (`24CAI0303` / Back End Engineering)

**Course Code & Name:** `24CAI0303` — Back End Engineering (Chitkara University)  
**Project:** Split Bro (Shared Expense Management & Debt Simplification Platform)  
**Active Syllabus Scope:** Continuous Assessment-1 (Lectures 1–24) & Continuous Assessment-2 (Lectures 25–41)
